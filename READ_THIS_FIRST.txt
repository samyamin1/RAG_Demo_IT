OPTION A: Downgrade to Python 3.11 (RECOMMENDED) ⭐
══════════════════════════════════════════════════════════════════════════

This is the EASIEST and FASTEST option!

Steps:
  1. Uninstall Python 3.14:
     Settings → Apps → Python 3.14.0 → Uninstall

  2. Download Python 3.11.10:
     https://www.python.org/ftp/python/3.11.10/python-3.11.10-amd64.exe

  3. Install Python 3.11:
     ⚠️ IMPORTANT: Check "Add Python to PATH"
     Click "Install Now"

  4. Open NEW PowerShell and verify:
     python --version
     (should show: Python 3.11.10)

  5. Delete old virtual environment:
     Remove-Item -Recurse -Force .venv

  6. Re-run automatic setup:
     python -m venv .venv
     .\.venv\Scripts\Activate.ps1
     pip install --upgrade pip
     pip install -r requirements.txt

Time: 10-15 minutes
Result: Everything will work perfectly! ✅

A: Settings → Apps → Find "Python 3.14.0" → Uninstall

   py -3.11 -m venv .venv
